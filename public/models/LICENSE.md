# Bundled models

All models under this directory are original Agentarium assets generated by the
Blender scripts in `assets/blender/`:

- `resident/colonist.glb`: the rigged, animated resident (`build_resident.py`).
- `world-kit/colony-hardware.glb`: shared colony hardware and habitat tiles
  (`build_world_kit.py`).
- `habitat/expedition-habitat.glb`: the reference habitat and material library
  (`build_habitat.py`).

No third-party model, rig, or motion-capture data is used. The former
RobotExpressive character (Tomás Laulhé, CC0, modified by Don McCurdy) was
replaced by the colonist and is no longer shipped.
