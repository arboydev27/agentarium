# Agentarium

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers, knowledge workers, and people running several AI tasks across tools.

## Product Purpose

Show what AI is working on, what needs attention, and what happened while the user was away. Persistent residents represent real sessions; selecting them provides task context and source links.

## Capabilities and Constraints

Keep the existing TypeScript, React, and Three.js stack. Preserve bridge integration, session identity, attention, task briefs, and the collection beyond the eight visible residents. Decorative activities must never imply provider activity. Unknown integration state remains unknown.

## Brand Commitments

The user approved reinventing the world as an alien colony on a Mars-like planet, with desert terrain, alien residents, habitats, exploration, and a space program. The surface is the product; the owner later removed the planet and solar-system views so the experience focuses on the colony and its horizon. This is a stylized fictional planet, not a scientific Mars simulator.

## Evidence on Hand

Existing application and docs/real-work.md; the user-approved implementation objective in this conversation.
